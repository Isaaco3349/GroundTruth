# Brand

UI colors follow the Nebius marketing hero: lime background accents, black typography, navy primary buttons.

Import tokens in the web app:

```css
@import "../../../assets/brand/colors.css";
```

Do not use the Nebius logomark in the hackathon UI unless official brand rules allow it. Prefer the wordmark **GroundTruth** in `--gt-black` on `--gt-lime` panels.
